# Чек-лист проверок GoShopix

## Визуал и UI

- [ ] Главная, каталог и карточка товара без горизонтального скролла на 375px / 768px / 1280px
- [ ] Бургер-меню открывается и закрывается на мобильном
- [ ] Кнопки и ссылки в навигации не меньше 44×44px
- [ ] Primary-кнопки цвета `#E31837`, статусы success/warning/error соответствуют токенам

## API

- [ ] `GET /api/health/ready` → 200 при работающей БД
- [ ] Вход `customer@goshopix.ru` / `password123` → 200 + JWT
- [ ] Каталог `/api/products` и `/api/categories` → 200 с данными
- [ ] Ошибки 401/404 отображают понятный текст в UI (не пустой JSON)

## Кроссбраузерность

- [ ] Chrome / Edge — полный сценарий покупателя
- [ ] Firefox или Safari — вход и каталог
- [ ] Мобильная эмуляция DevTools — сетка каталога 1 колонка

## Перед релизом

- [ ] `npm run build` без ошибок
- [ ] `npm run test:unit -w server` зелёный
- [ ] `npm run lint` без критичных ошибок
